What the optimizer actually saves.

Every fixture is a captured tool result. SUTRA measures the visible result, not a provider bill: byte counts are exact, token counts use the o200k_base encoding, and latency is a local median. No model calls are made.

Read the totals honestly. Many fixtures are small enough that the deterministic head/tail pass leaves them unchanged. Per-case rows and the top-savings chart show where compression is doing real work.
